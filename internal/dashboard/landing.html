VEXLO Open dashboard
Quick tunnels for developers

Expose local apps. Inspect every request.

Vexlo securely connects a local development server to a public URL, captures HTTP traffic, and lets you inspect or replay requests from your dashboard.

One command to install, then vexlo http 3000. No account or shared token is required.

macOS / Linux

curl -fsSL https://vexlo.duckdns.org/install.sh | sh

Windows PowerShell

irm https://vexlo.duckdns.org/install.ps1 | iex
Open dashboard View on GitHub

Local to public

Connect a local port through an encrypted tunnel and receive a public address.

Inspect and replay

Review captured requests and responses, then replay or mutate them during development.

Security by default

TLS, temporary URLs, body limits, retention controls, and a private dashboard protect the service. Anyone with your public tunnel URL can reach your local app while it is connected.

Keep your dashboard link private. Stop the CLI to close the tunnel.
